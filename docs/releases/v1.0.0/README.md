# Meteofy v1.0.0

## Overview

Meteofy v1.0.0 is the first documented release of the application, preserving its original interface and feature set before the planned UI redesign.

This release provides a reference point for the initial version of Meteofy, including its functionality, responsive layouts, and visual appearance. The `v1.0.0` tag identifies the exact codebase associated with this release.

## Features

- Current weather dashboard with a 15-day forecast and city search
- Interactive map of Poland featuring provincial capitals
- Interactive map of Europe featuring national capitals
- Interactive 3D globe featuring world capitals
- Long-term weather charts with selectable date ranges, metrics, and cities
- Air pollution monitoring with current conditions, forecasts, and charts
- Light and dark themes
- Responsive layouts for desktop and mobile devices

## Release Notes

This release documents the original Meteofy interface before the planned v2.0.0 redesign. The screenshots and source code serve as a historical reference for the initial release.

The `v1.0.0` tag should remain unchanged to preserve a stable reference to this version. Future features, interface changes, and documentation updates should be introduced in subsequent releases, such as `v2.0.0`.
